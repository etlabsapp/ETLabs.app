@ 1
On a Kubernetes cluster, which resource do you create to make an app's port reachable from the internet?
- Pod :: A pod runs the containers but only has an internal address that changes when it is recreated.
- Deployment :: A Deployment keeps the right number of pod copies running. It does not expose any port.
* Service :: A Service gives a set of pods one stable address and port. With type LoadBalancer (or NodePort) it is reachable from outside the cluster, and on a cloud cluster LoadBalancer gets a public IP.
- Network :: Network is not a standard Kubernetes resource. NetworkPolicy only filters traffic and publishes nothing.

An admin must check whether an app on 10.44.7.21 answers on TCP port 9090 from another machine. Which command does this?
- ssh 10.44.7.21 -p 9090 :: ssh would try to speak SSH to the port, and the errors would not clearly show whether it is open.
- traceroute 10.44.7.21:9090 :: traceroute shows the route to a host and does not take host:port.
- tcpdump 'host 10.44.7.21 and port 9090' :: tcpdump only watches traffic. It sends nothing, so it cannot test the port by itself.
* nc -v 10.44.7.21 9090 :: nc -v tries a TCP connection to that address and port and reports success or failure, a direct test of one remote port.

@ 95
Which command converts a KVM disk image from one format to another, such as raw to qcow2?
* qemu-img :: qemu-img convert -f raw -O qcow2 in.img out.qcow2 changes formats. qemu-img also creates, resizes and inspects images.
- qemu-io :: qemu-io tests read and write operations on an image.
- qemu-kvm :: qemu-kvm runs virtual machines.
- qemu-nbd :: qemu-nbd shares an image as a network block device. It does not convert it.

@ 96
An admin is setting up two new servers and wants passwordless login from this one to server2 as user maya. Which command does this?
- ssh-agent -i rsa && ssh-copy-id ~/.ssh/key maya@server2 :: ssh-agent holds keys in memory and does not make them, and ssh-copy-id needs -i before a key file.
* ssh-keygen -t rsa && ssh-copy-id -i ~/.ssh/id_rsa.pub maya@server2 :: ssh-keygen makes the key pair, and ssh-copy-id appends the public key to maya's ~/.ssh/authorized_keys on server2. After that, key login works with no password.
- ssh-keyscan -t rsa && ssh-copy-id maya@server2 -i ~/.ssh/key :: ssh-keyscan collects other servers' host keys and needs a host name. It does not make a key pair.
- ssh-add -t rsa && scp -rp ~/.ssh maya@server2 :: ssh-add loads keys into the agent, and copying the whole .ssh folder would send the private key to the server.

@ 97
An admin needs to securely wipe everything on the disk /dev/sdc. Which command is best?
- sudo dd if=/dev/null of=/dev/sdc1 :: /dev/null gives no data, so dd writes nothing, and this targets one partition.
- sudo rm -rf /dev/sdc1 :: This only deletes the device file in /dev. The data on the disk is untouched.
- sudo parted /dev/sdc rm 1 :: This deletes a partition entry, but the data stays on the disk.
* sudo shred /dev/sdc :: shred overwrites the whole device several times with random data, so the old contents cannot be recovered. Add -z for a final pass of zeros.

@ 98
A script should print "CLEAN" only when the word ERROR appears zero times in a log:
```
if [ $(grep -c ERROR /var/log/app.log) __ 0 ]
then
    echo CLEAN
else
    echo PROBLEMS
fi
```
Which operator belongs in the blank?
- -gt :: -gt means greater than, so CLEAN would print when errors were found.
* -eq :: grep -c prints how many lines contain ERROR, and -eq tests whether two numbers are equal. The test is true only when the count is 0.
- -ne :: -ne means not equal, which would print CLEAN whenever errors were found.
- -lt :: A count can never be below zero, so the test would never be true.

@ 99
What is journald?
- A service that creates crash dumps when the kernel fails :: That is kdump.
- The service that keeps the filesystem journal :: Filesystem journaling is part of the filesystem itself, like ext4 or XFS.
- A service that writes audit records to disk :: That is auditd.
* A system service that collects and stores logs :: systemd-journald gathers messages from the kernel, services and programs and stores them in a structured journal that you read with journalctl.

@ 100
Which PAM module can be used to spot and block repeated password-guessing (dictionary) attacks?
- pam_unix :: pam_unix checks passwords against /etc/shadow. It does not count failures.
* pam_tally2 :: pam_tally2 counts failed logins and locks the account after a set number. (Newer distributions replaced it with pam_faillock, which does the same job.)
- pam_ldap :: pam_ldap checks logins against an LDAP directory.
- pam_limits :: pam_limits sets resource limits like open files or processes per user.
