Questions about free QR codes

Do free QR codes expire?

Codes made here don't expire. They're static: your link or text goes straight into the code with no redirect, so the code keeps working as long as the link it points to does.

Is this really free?

Yes. There's no sign-up, no paywall and no watermark, and PNG and SVG downloads are free.

What's the difference between a static and a dynamic QR code?

A static QR code stores your content directly in the pattern, so it doesn't depend on any service, but it can't be changed after it's printed. A dynamic QR code stores a short link that redirects through a service, so the destination can be edited later, but the code works only while that service keeps the link active.

What can I put in a QR code here?

A website link, plain text, Wi-Fi network details, or an email address with an optional subject and message.

How do I make a Wi-Fi QR code?

Choose Wi-Fi, then enter the network name, security type and password. Phones that support Wi-Fi QR codes can join the network by scanning it.

What file formats can I download?

PNG from 256 to 2048 pixels, or SVG, which scales to any size. You can also print the code directly.
